9장 04  Ollama SDK와 LangChain 호출 비교


핵심 이해

Ollama는 로컬 모델 서버이며 OpenAI 호환 API의 일부를 제공한다.
같은 로컬 모델을 OpenAI SDK 또는 ChatOllama로 호출할 수 있다.
SDK를 쓴다는 이유로 OpenAI의 서버에 요청하는 것은 아니다.


준비와 SDK 흐름

Ollama 서버 실행 → ollama list로 모델 확인 → OpenAI 호환 endpoint 연결.
base_url='http://localhost:11434/v1' → 로컬 Ollama 서버.
api_key='ollama' → SDK가 요구하는 형식용 값. 기본 로컬 서버에서는 실제 인증에 사용되지 않는다.
model='exaone3.5:2.4b' → 원문의 다운로드 모델명.
chat.completions.create(messages=...,stream=False) → 완성된 응답 받기.
choices[0].message.content → 답변. response.usage → 서버가 제공하는 사용량 정보.


LangChain 흐름

ChatOllama(model='exaone3.5:2.4b') → SystemMessage·HumanMessage 전달 → invoke() → content.
외부 API 키보다 로컬 서버의 실행 상태·모델 설치 여부를 먼저 확인한다.
연결 실패 → 서버 주소·포트·실행 상태. 모델 없음 → ollama list와 정확한 태그 확인.


비교 해석

%%time → Jupyter 셀의 실행 시간 측정. 일반 Python 스크립트의 문법이 아니다.
최초 호출에는 모델 로딩 시간이 포함될 수 있다. 재호출 시간과 구분한다.
시간은 모델 크기·CPU/GPU·메모리·입출력 길이·백그라운드 부하의 영향을 받는다.
SDK 예제에는 temperature=0.5가 있고 ChatOllama 예제에는 명시되어 있지 않다. 비교 시 같은 설정을 맞춘다.
로컬 실행에는 외부 토큰 API 요금이 없더라도 장비·전력·시간 비용이 있다.
Ollama 자체가 한국어를 지원하지 않는다고 단정하지 않는다. 선택한 모델의 언어 능력을 확인한다.


필수 함수

OpenAI(base_url=...), chat.completions.create(), ChatOllama(), invoke().
ollama list → 모델 이름 확인. %%time → 노트북 시간 측정.
