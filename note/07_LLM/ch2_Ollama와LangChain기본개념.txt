2장  Ollama와 LangChain 기본 개념


핵심 이해

Ollama → 로컬에서 LLM을 실행하는 도구. LangChain → LLM 호출과 주변 처리를 연결하는 프레임워크.
ChatOllama·ChatOpenAI → 서로 다른 제공자의 채팅 모델을 연결하는 클래스.
invoke() → 입력을 전달해 실행. 채팅 모델은 보통 AIMessage를 반환하며 content에 답변이 있다.
모델·프롬프트·파서는 Runnable 인터페이스를 사용해 체인으로 연결할 수 있다.


전체 흐름

모델 준비 → 프롬프트 템플릿 → 변수 주입 → 모델 호출 → 출력 파싱 → LCEL 체인 구성.
예제 모델 → llama3.2:1b·deepseek-r1:1.5b·exaone3.5:2.4b, API 예제의 gpt-4.1-nano.
한국어 성능과 지원 여부는 Ollama 자체보다 선택한 모델·버전·규모에 따라 달라진다.


프롬프트와 메시지

PromptTemplate → {country} 같은 변수에 값을 넣어 문자열 프롬프트 생성.
invoke() 반환 → PromptValue 객체. format() 반환 → 문자열. 모델은 PromptValue를 입력으로 받을 수 있다.
input_variables → 필요한 변수 이름. invoke({'country':'Korea'}) → 이름과 값을 명확히 연결.
SystemMessage → 역할·지침. HumanMessage → 사용자 입력. AIMessage → 모델 답변. ToolMessage → 도구 결과.
ChatPromptTemplate → 역할 메시지를 포함하는 템플릿. ('human', '질문')처럼 튜플로 만들 수 있다.
few-shot → 질문과 모범 답변을 몇 개 제공해 원하는 응답 형태를 보여준다.
파라미터가 하나인 템플릿의 단일 값 입력과 일반 딕셔너리 입력을 구분한다. {'Korea'}는 딕셔너리가 아니라 집합이다.


출력 형식

StrOutputParser → 모델 응답을 문자열로 변환.
JsonOutputParser → JSON 형태의 출력을 파싱. 파싱 결과는 입력 구조에 따라 dict·list 등이 될 수 있다.
JSON은 문자열 키와 문자열 값에 큰따옴표를 쓴다. 작은따옴표를 쓰는 Python 딕셔너리 표기와 다르다.
BaseModel·Field → Pydantic으로 필드의 타입·범위·설명을 정의한다.
gt·ge → 초과·이상. lt·le → 미만·이하. min_length → 최소 길이.
with_structured_output(CountryDetail) → 정의한 스키마에 맞는 출력 요청. 모델의 기능 지원을 확인한다.
model_dump() → Pydantic 객체를 딕셔너리로 변환.
형식이 맞아도 인구 같은 실제 사실이 맞는지는 따로 확인한다.


LCEL 연결

LCEL(LangChain Expression Language) → | 기호로 실행 단계를 연결하는 방식.
capital_chain = prompt_template | llm | StrOutputParser()
capital_chain.invoke({'country':'Korea'}) → 템플릿 생성·모델 호출·문자열 추출을 한 번에 수행.

국가 설명 → 국가명 → 수도명으로 이어지는 경우:
final_chain = {'country': country_chain} | capital_chain
앞 체인의 결과를 다음 체인이 요구하는 country 키로 전달한다.
단일 변수 템플릿은 문자열 결과를 직접 받을 수도 있지만 키를 붙이면 입력 구조가 분명해진다.
각 체인의 입력 변수와 출력 자료형을 먼저 확인한다.


필수 함수와 점검

ChatOllama(), ChatOpenAI(), invoke() → 모델 생성과 호출.
PromptTemplate(), ChatPromptTemplate() → 프롬프트 구성.
StrOutputParser(), JsonOutputParser(), with_structured_output() → 결과 형식 처리.
예제의 imvoke는 invoke 오타다. ChatAnthropic 예제의 import도 별도 확인이 필요하다.
answer() → 나라를 받아 수도 질문을 만들고 result.content를 반환하는 함수 예시.
