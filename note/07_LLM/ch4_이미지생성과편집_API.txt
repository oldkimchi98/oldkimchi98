4장  이미지 생성과 편집 API


핵심 이해

이미지 생성 → 텍스트 설명으로 새로운 이미지를 만든다.
이미지 편집 → 기존 이미지와 수정 지시를 함께 전달한다.
Inpainting → 내부의 일부 영역을 수정. Outpainting → 확장한 캔버스의 빈 영역을 생성.
예제 모델 → gpt-image-1-mini. 새 모델의 옵션과 예제 모델의 옵션을 혼용하지 않는다.


전체 흐름

환경 설정 → 이미지 생성 요청 → Base64 결과 추출 → bytes로 디코딩 → PNG 저장 → 표시.
편집 → 원본 이미지와 마스크 준비 → edit() → 결과 디코딩 → 새 파일 저장.


생성 옵션과 결과

client.images.generate() → 텍스트를 이미지로 생성.
prompt → 대상·구도·색·분위기·스타일 설명. n → 이미지 수. size → 결과 크기.
예제의 size → 1024x1024. quality='low' → 낮은 품질 설정. 지원하는 값은 모델별로 확인한다.
style 옵션을 다른 이미지 모델에서 그대로 가져오지 않는다. 원하는 스타일은 prompt에 구체적으로 적는다.
response.data[0].b64_json → Base64로 표현된 이미지 데이터.
base64.b64decode() → Base64 문자열을 원래 바이너리 bytes로 복원.
with open(...,'wb') → 이미지 파일 저장. 확장자만 바꾼다고 파일 형식이 변하지는 않는다.


마스크 편집

client.images.edit() → 원본과 편집 지시 전달.
mask → 알파 채널이 있는 마스크. 투명 영역이 편집 영역을 나타낸다.
원본과 마스크의 크기·파일 형식을 맞춘다. 예제 파일들은 1024x1024 PNG다.
마스크를 전달해도 생성 결과의 다른 영역이 완전히 동일하게 유지된다고 보장하지 않는다.
open(...,'rb') → 입력 바이너리 읽기. with 문으로 원본과 마스크 파일을 닫는 흐름을 구성한다.


이미지 표시와 크기 변경

IPython.display.Image → 노트북에 이미지를 표시.
PIL.Image.open(BytesIO(image_bytes)) → 메모리의 이미지 읽기.
resize((가로,세로)) → 새 이미지 객체를 반환. 기존 파일 자체를 변경하지 않는다.
작은 미리보기와 API가 생성한 원본 해상도를 구분한다.
같은 이름으로 저장하면 앞선 이미지가 덮어써질 수 있으므로 비교 결과는 다른 이름으로 저장한다.


필수 함수

images.generate(), images.edit(), base64.b64decode() → 생성·편집·데이터 복원.
open(), write(), Image.open(), BytesIO(), resize() → 파일 저장과 표시.
