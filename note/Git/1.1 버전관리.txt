버전 관리

로컬
관리 방법 : 자기 컴퓨터에 변경 이력 저장 
장점과 한계 : 간단하지만 컴퓨터나 저장 장치가 손상되면 이력을 잃을 수 있음

중앙집중식 
관리 방법 : 중앙 서버에 이력을 두고 함께 작업
장점과 한계 : 협업·관리가 편하지만 서버 장애에 취약함. 

분산식
관리 방법 : 각 컴퓨터가 파일과 전체 이력을 복제
장점과 한계 : 복제본으로 복구할 수 있고 다양한 협업 방식 지원


버전 관리 시스템(VCS - Version Control System)
-> RCS(Revision Control System) : 기본적으로 Patch Set(파일에서 변경되는 부분)을 관리

중앙집중식 버전 관리(CVCS)

분산 버전 관리 시스템(DVCS)
