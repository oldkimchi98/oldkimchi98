Git 기초 요약

1. 스냅샷(Snapshot)
- Git은 커밋할 때 프로젝트의 그 시점 상태를 기록한다.
- 변경되지 않은 파일은 기존 데이터를 재사용한다.

2. 로컬 작업(Local)
- 이력 조회, 파일 비교, 커밋을 내 컴퓨터에서 처리한다.
- 인터넷에 연결하지 않아도 작업할 수 있다.

3. 무결성(Integrity)
- 파일 내용 등으로 계산한 해시(Hash)로 데이터를 식별한다.
- 이를 통해 데이터 변경이나 손상을 감지한다.

4. 데이터 추가
- Git은 주로 저장소에 데이터를 추가하는 방식으로 작동한다.
- 커밋한 기록은 복구에 도움이 된다.
- 커밋하지 않은 변경은 잃을 수 있다.

5. 파일의 세 가지 상태
- Modified(수정됨): 파일을 수정한 상태
- Staged(준비됨): 다음 커밋에 넣을 내용을 선택한 상태
- Committed(기록됨): 내용을 로컬 저장소에 기록한 상태

6. 세 가지 작업 공간
- Working Tree: 실제 파일을 수정하는 작업 폴더
- Staging Area / Index: 다음 커밋에 넣을 내용을 준비하는 영역
- Git Directory: 커밋과 변경 이력을 보관하는 저장소

7. 기본 작업 순서
파일 수정 → git add → git commit

- git add: 커밋할 내용을 준비한다.
- git commit: 준비한 내용을 하나의 버전으로 기록한다.
- 파일 저장과 커밋은 별개의 작업이다.
