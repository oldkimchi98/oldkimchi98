Flask  ch5_testdb 공통 템플릿과 정적 파일

참고 폴더 : C:\ai\lecNote\10_flask\ch5_testdb


1절  현재 폴더의 학습 내용

공통 HTML 틀 → 머리말·본문·꼬리말 조합 → Bootstrap과 사용자 CSS 적용 → 브라우저 표시
폴더 이름은 ch5_testdb지만 현재 파일에는 DB 연결·SQL·CRUD 코드가 없다.
현재 확인된 내용은 Jinja2 공통 템플릿과 CSS·이미지 사용이다.
app.py와 Flask 라우트도 없어 이 폴더만으로 웹 실행 흐름 전체를 확인할 수 없다.


2절  폴더와 파일의 역할

templates/base.html → 여러 화면에서 공유할 기본 HTML 구조
templates/header.html → 로고·제목을 표시하는 공통 머리말
templates/footer.html → 저작권 문구와 스타일을 담은 공통 꼬리말
static/css/file.css → 배경·제목·이미지·표 디자인
static/img/flask.png → 머리말 로고와 브라우저 탭 아이콘
templates → 서버가 데이터를 넣어 완성할 HTML 틀
static → CSS·이미지처럼 그대로 제공하는 정적 파일


3절  base.html의 문서 구조

<!DOCTYPE html> → HTML5 문서임을 선언
<html lang="en"> → 문서의 기본 언어를 영어로 지정한 현재 설정
<head> → 인코딩·화면 크기·탭 제목·스타일 같은 문서 정보
<meta charset="UTF-8"> → 한글 등 문자를 UTF-8로 처리
viewport → 모바일 화면의 표시 폭과 초기 확대 비율 설정
width=device-width → 표시 폭을 기기 화면 폭에 맞춤
initial-scale=1.0 → 초기 확대 비율을 1로 설정
<body> → 브라우저 화면에 표시할 내용
class="container py-4" → Bootstrap의 반응형 컨테이너와 위·아래 여백


4절  Jinja2의 상속과 포함

{% block title %}{% endblock %} → 자식 템플릿이 탭 제목을 채울 영역
{% block content %}{% endblock %} → 자식 템플릿이 본문을 채울 영역
{% include "header.html" %} → 머리말을 해당 위치에 포함
{% include "footer.html" %} → 꼬리말을 해당 위치에 포함
{% extends "base.html" %} → 자식 템플릿에서 공통 틀을 상속할 때 사용하는 문법
현재 폴더에는 extends를 사용하는 자식 페이지가 없고 base.html에 상속용 영역만 준비되어 있다.
include → 다른 파일의 내용을 현재 위치에 넣기
block → 자식 템플릿이 바꿔 넣을 영역 지정
Jinja2는 서버에서 처리되며 브라우저에는 처리된 HTML이 전달된다.


5절  정적 파일 주소와 외부 CSS

{{ url_for('static', filename='img/flask.png') }} → Flask가 정적 이미지 URL을 생성
{{ url_for('static', filename='css/file.css') }} → Flask가 사용자 CSS URL을 생성
url_for는 Flask가 템플릿에 제공하는 함수다.
filename은 static 폴더 안에서의 상대 경로이며 static/을 다시 붙이지 않는다.
<link ... rel="icon"> → 브라우저 탭 아이콘 지정
<link ... rel="stylesheet"> → CSS 파일 불러오기
현재 Bootstrap CSS 버전 → 5.3.8
CDN 주소 → 외부 서버에서 Bootstrap CSS를 가져옴
불러오는 순서 → Bootstrap CSS → file.css
나중 CSS가 항상 이기는 것은 아니다. 중요도·선택자 우선순위 등이 같을 때 뒤 규칙이 적용된다.
현재 base.html에는 Bootstrap JavaScript를 불러오는 script 태그가 없다.


6절  header.html의 항목

<header> → 공통 머리말 영역
<a href="/"> → 로고와 제목을 클릭하면 루트 주소로 이동
<img src="..."> → flask.png를 로고로 표시
width="32", height="16" → HTML에 지정한 이미지 크기
pb-3 → 아래쪽 내부 여백
mb-4 → 아래쪽 외부 여백
border-bottom → 아래쪽 테두리
d-flex → Flex 배치 사용
align-items-center → 기본 가로 Flex 배치에서 세로 방향 가운데 정렬
text-body-emphasis → 강조된 본문 글자색
text-decoration-none → 링크 밑줄 등 글자 장식 제거
me-3 → 끝 방향 외부 여백. 현재처럼 왼쪽에서 오른쪽으로 읽는 배치에서는 오른쪽 여백
fs-4 → Bootstrap 글자 크기 클래스
현재 표시 제목 → Jinja2문법
기존 주석의 Alt+Shift+F → 에디터의 코드 정리 단축키 안내이며 웹페이지 기능은 아니다.


7절  file.css의 선택자와 스타일

body → 페이지 전체 배경을 lightyellow로 지정
h1 → 큰 제목 글자색 blue
h2 → 두 번째 제목 글자색 darkgreen
img → 모든 이미지의 CSS 폭을 100px로 지정
table → 2px 두께, 실선, #444444 색의 테두리
border-collapse: collapse → 표 셀 사이의 테두리를 합쳐 표시
thead → 표 머리글 영역 배경을 bisque로 지정
td → 데이터 셀의 글자를 가운데 정렬하고 폭을 10%로 지정
선택자 { 속성: 값; } → CSS 기본 작성 형식
px → 픽셀 길이 / % → 기준 크기에 대한 비율
현재 폴더에는 h1·h2·table을 사용하는 본문 페이지가 없다. 관련 CSS는 준비된 규칙이다.


8절  footer.html의 항목

<footer> → 공통 꼬리말 영역
site-footer → 붙여둔 사용자 클래스 이름. 현재 file.css에는 이 클래스의 규칙이 없다.
mt-4 → Bootstrap 위쪽 외부 여백
copyright → 저작권 문구에 붙여둔 클래스 이름
<style> → HTML 내부에 CSS 작성
footer { ... } → 모든 footer 요소에 적용
width:100% → 부모 기준 전체 폭
margin:5px auto → 위·아래 5px, 좌·우 자동 여백
height:150px → footer 높이 150px
overflow:hidden → 영역 밖으로 넘치는 내용을 숨김
footer div:last-child → footer 안에서 부모의 마지막 자식인 div를 선택
height:50px, line-height:50px → 한 줄 문구의 세로 가운데 정렬에 사용하는 동일 높이
text-align:center → 글자 가로 가운데 정렬
background-color:black, color:white → 검은 배경과 흰 글자


9절  주석 작성 방식

{# 설명 #} → Jinja2 주석. 서버에서 제거되어 브라우저에 전달되지 않는다.
<!-- 설명 --> → HTML 주석. 화면에는 안 보이지만 페이지 소스에는 남는다.
/* 설명 */ → CSS 주석. CSS 규칙 실행에 영향을 주지 않는다.
이번 작업은 HTML과 CSS에 항목별 설명 주석을 추가했으며 기존 코드 줄은 그대로 유지했다.


10절  현재 코드에서 기억할 부분

① footer.html은 <!DOCTYPE>, html, head, body를 가진 전체 HTML 문서다.
   base.html의 body 안에 include되므로 문서 구조가 중첩된다.
   공통 조각 파일은 footer 요소와 필요한 스타일 중심으로 구성하는 편이 적절하다.
② header의 이미지에는 width=32가 있지만 file.css의 img {width:100px;}가 CSS 폭으로 적용된다.
   로고만 별도 크기를 쓰려면 전용 선택자로 구분할 수 있다. 이번 작업에서는 크기를 바꾸지 않았다.
③ footer 내부 CSS는 base.html의 외부 CSS보다 뒤에 나오지만 최종 결과는 선택자 우선순위 등도 함께 확인해야 한다.
④ Bootstrap의 mt-4 여백 유틸리티는 !important를 사용하므로 일반 margin 규칙과 충돌할 때 이를 함께 고려한다.
⑤ 파일명만 보고 DB 학습 내용을 추정하지 않는다. 현재 폴더에는 DB 접속 설정·모델·저장소·SQL 파일이 없다.
⑥ 웹 실행 파일이 없어 실제 서버 실행 확인은 하지 않았다. 템플릿 문법과 렌더링 결과를 확인했다.


11절  핵심 복습

base.html → 공통 틀 / include → 공통 조각 포함 / block → 자식 페이지가 채울 영역
url_for('static', filename=...) → CSS·이미지 주소 생성
Bootstrap → 기본 디자인·배치 / file.css → 사용자 스타일
HTML → 구조 / Jinja2 → 서버에서 화면 조합 / CSS → 디자인
