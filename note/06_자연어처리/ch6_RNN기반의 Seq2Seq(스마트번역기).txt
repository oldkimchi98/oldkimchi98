6장  RNN 기반 Seq2Seq 스마트 번역기


핵심 이해

Seq2Seq → 입력 시퀀스를 읽는 인코더와 출력 시퀀스를 만드는 디코더를 연결한다.
수업 목표 → translate.csv의 짧은 영어 단어를 한국어로 변환. 단어 단위가 아닌 문자 단위로 인코딩한다.
인코더 → 영어를 읽어 상태 생성. 디코더 → 인코더 상태를 받아 한국어 문자를 출력.


전체 흐름

영·한 데이터 읽기 → 문자 목록과 번호 사전 생성 → 인코더 입력·디코더 입력·타겟 준비 → LSTM 상태 연결 → 문자별 softmax 학습 → 예측 번호를 문자로 복원.
문자 사전 → 영어, 한국어와 특수 문자 S·E·P. 수업에서는 테스트용 pp 문자열도 사용한다.


입력과 타겟

cold → 감기 예시. 인코더 입력 → cold. 디코더 입력 → S감기. 디코더 타겟 → 감기E.
S → 시작 표시. E → 종료 표시. 디코더 입력과 타겟을 한 칸 이동해 다음 문자를 학습한다.
인코더·디코더 입력 → 원핫 인코딩. 디코더 타겟 → 정수 문자 번호.
수업 입력 길이 → 영어 4, 디코더 3. 입력 배열 → (샘플 수, 시점 수, 문자 종류 수).
타겟 배열 → 수업은 (샘플 수, 디코더 시점 수, 1)로 구성한다. 다른 길이의 단어에는 길이 통일 처리가 필요하다.


모델 구조

인코더 LSTM(return_state=True) → 마지막 state_h와 state_c를 반환한다.
디코더 LSTM(initial_state=[state_h, state_c]) → 인코더 상태로 시작한다.
return_sequences=True → 디코더의 모든 시점 출력을 반환한다.
Dense(문자 종류 수, softmax) → 각 시점의 다음 문자 확률.
sparse_categorical_crossentropy → 원핫 인코딩하지 않은 정수 타겟에 사용. 수업은 rmsprop, 500 epochs로 학습한다.


모델 사용

predict() → 시점별 문자 확률. argmax(axis=-1) → 문자 번호 선택. alpha[번호] → 문자 복원.
학습 중 정답의 이전 문자를 넣는 방식 → teacher forcing. 실제 순차 번역에서는 이전 예측 문자를 다음 입력으로 사용한다.
수업의 'Spp' 입력으로 한 번에 예측하는 실습과 순차 디코딩을 구분한다. 종료 문자 E를 기준으로 결과를 읽는다.
학습 데이터 평가 → 학습한 단어를 익혔는지 확인. 오타 단어 실습 → 문자 순서 변화에 대한 반응 확인.


필수 함수

read_csv() → 영·한 데이터 읽기. to_categorical() 또는 np.eye() → 문자 원핫 인코딩.
Input(), LSTM(), Model() → 두 입력과 상태 연결 구성. Dense() → 문자별 분류.
fit(), evaluate(), predict(), argmax() → 학습과 번역 결과 확인.
