8장  Attention 스마트 번역기


핵심 이해

Attention → 디코더가 출력 문자를 만들 때 인코더의 여러 시점 중 관련 있는 정보를 가중합해 참고한다.
기본 Seq2Seq → 인코더 마지막 상태를 디코더에 전달. Attention 추가 → 마지막 상태와 함께 인코더의 전체 시점 출력도 활용.
수업 목표 → 6장의 문자 단위 영·한 번역 모델에 Attention을 추가한다.


전체 흐름

문자 사전과 번역 입력 준비 → 인코더의 전체 출력·마지막 상태 생성 → 마지막 상태로 디코더 초기화 → 디코더·인코더 출력으로 Attention 계산 → 문맥 벡터와 디코더 출력 결합 → 문자별 softmax → 학습과 번역.
입력·타겟 → 영어 입력, S+한국어 디코더 입력, 한국어+E 정수 타겟. 6장과 같은 전처리 기준을 사용한다.


Attention 연결

인코더 LSTM → return_sequences=True와 return_state=True. ENC_OUT은 모든 시점의 출력, state_h와 state_c는 마지막 상태.
디코더 LSTM → initial_state=[state_h, state_c], return_sequences=True로 시점별 출력 DEC_MID 생성.
Attention()([DEC_MID, ENC_OUT]) → 디코더 출력을 query, 인코더 출력을 value로 사용한다. 별도 key가 없으면 value가 key도 맡는다.
문맥 벡터 → 각 디코더 시점에서 인코더 출력을 관련도에 따라 가중합한 결과.
Concatenate()([CONTEXT_VECTOR, DEC_MID]) → 문맥 정보와 디코더 상태를 마지막 차원에서 연결한다.
Dense(문자 종류 수, softmax) → 결합된 정보로 다음 문자를 분류한다.


배열과 학습

인코더 출력 → (샘플 수, 영어 길이 4, hidden 128). 디코더 출력 → (샘플 수, 디코더 길이 3, hidden 128).
Attention 결과 → 디코더의 각 시점에 대응하는 문맥 벡터. 연결 후 마지막 차원은 hidden의 두 배.
정수 타겟 → sparse_categorical_crossentropy. 수업 학습 → rmsprop, 500 epochs.
시점 수와 특징 차원을 구분한다. Attention 계산 결과와 문자 분류 확률은 서로 다른 값이다.


번역 결과 읽기

argmax(axis=-1) → 각 시점의 예측 문자 번호. 문자 사전으로 복원하고 E 종료 표시를 확인한다.
수업은 학습 단어와 순서를 바꾼 오타 단어를 비교한다. 학습셋 결과와 새로운 단어에 대한 성능을 구분한다.
실제 순차 번역 → S에서 시작해 이전 예측 문자를 다음 입력으로 넣으며 종료할 때까지 진행한다.


필수 함수

LSTM(return_sequences=True, return_state=True) → 전체 출력과 마지막 상태.
Attention() → 인코더 정보의 가중합. Concatenate() → 문맥 벡터와 디코더 출력 연결.
Model(), fit(), predict(), argmax() → 모델 구성과 결과 확인.
