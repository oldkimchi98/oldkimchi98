5장  LSTM 영화평 감성분석


핵심 이해

목표 → IMDB 영화평을 부정 0, 긍정 1로 분류한다. 분석 자료는 총 5만 개 영화평을 학습·시험 데이터로 나누어 제공한다.
LSTM → 일반 RNN에서 긴 문맥을 학습하기 어려운 점을 보완한다. 은닉상태와 셀 상태로 정보를 전달한다.
입력·망각·출력 게이트 → 정보를 선택하고 유지하는 역할. GRU도 순환신경망의 개선 구조다.


전체 흐름

IMDB 정수 데이터 읽기 → 라벨 비율과 영화평 길이 확인 → 길이 통일 → Embedding·LSTM·sigmoid 구성 → 검증셋으로 학습 점검 → 시험셋 평가 → 새 영화평 정수화와 예측.
예제 설정 → 어휘 10000개, 길이 80, 임베딩 32차원, LSTM 64 units, epochs=10, batch_size=200.
길이를 늘리면 더 많은 문맥을 반영하지만 계산량도 증가한다.


정수 번호와 패딩

imdb.get_word_index() → 단어 사전. 기본 IMDB 리뷰 번호는 사전 번호에 3을 더해 사용한다.
0 → 패딩. 1 → 시작. 2 → 미등록 또는 어휘 제한으로 제외된 단어. 3 → 기본 설정에서 예약된 번호.
새 리뷰 → 소문자화와 문자 정리 → 단어 분리 → 사전 번호+3 → 미등록·범위 밖 번호를 2로 변경 → 시작 번호 1 추가.
예제 패딩 → maxlen=80, truncating='post'로 뒤를 자르고 padding='pre'로 앞에 0을 채운다.
학습·시험·새 입력에 같은 정수화와 길이 기준을 적용한다. SKIP_TOP 변수만 선언하면 불용어 제외가 실행되는 것은 아니다.


모델과 과적합 제어

Embedding(10000, 32) → 단어 벡터. LSTM(64) → 문맥 요약. Dense(1, sigmoid) → 긍정 확률.
binary_crossentropy → 0/1 타겟의 이진 분류 손실. optimizer='adam' → 가중치 업데이트.
dropout → 입력 연결 일부 제외. recurrent_dropout → 이전 은닉상태의 순환 연결 일부 제외.
l2 → 큰 가중치에 규제. EarlyStopping → val_loss가 개선되지 않으면 학습 중단.
예제 기준 → patience=3, restore_best_weights=True로 가장 낮은 검증 손실 시점의 가중치 복원.


평가와 예측

학습·검증 loss와 accuracy를 함께 비교한다. evaluate()로 시험셋 성능 확인.
predict() → 확률. (pred > 0.5).astype(int) → 최종 0/1 분류.
정확도 → 전체 정답 비율. 정밀도 → 긍정 예측 중 실제 긍정 비율. 재현율 → 실제 긍정 중 찾아낸 비율.
F1 → 정밀도와 재현율의 조화평균. confusion_matrix() → 실제·예측 라벨 비교.


필수 함수

imdb.load_data() → 데이터 읽기. pad_sequences() → 길이 통일.
Embedding(), LSTM(), Dense() → 모델 구성. EarlyStopping() → 학습 중단 조건.
evaluate(), predict(), confusion_matrix(), precision_score(), recall_score(), f1_score() → 평가와 분류.
