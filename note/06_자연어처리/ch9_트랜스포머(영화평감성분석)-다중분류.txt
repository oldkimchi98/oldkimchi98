9장  트랜스포머 영화평 감성분석  softmax 분류


핵심 이해

목표 → 같은 부정·긍정 문제를 두 개의 softmax 출력으로 표현한다.
파일 이름은 다중분류지만 예제 데이터의 실제 클래스는 부정 0, 긍정 1의 두 가지다. 인코더 구조는 이진분류 노트와 같다.
sigmoid → 긍정 확률 하나. softmax → 부정과 긍정 확률을 각각 출력하며 합이 1이 된다.


전체 흐름

IMDB 데이터와 정수 타겟 확인 → 패딩 → 단어·위치 임베딩 → Self Attention → 잔차 연결·정규화 → FFN → 평균 풀링 → Dense(2, softmax) → 학습 → argmax로 클래스 선택 → 평가.
공통 설정 → 어휘 10000개, 길이 80, 임베딩 32, hidden 64. 동일한 전처리 기준으로 출력 방식의 차이를 비교한다.


출력과 손실함수

예제 구성 → Dense(2, softmax), 타겟은 원핫 인코딩하지 않은 정수 0/1, sparse_categorical_crossentropy.
원핫 타겟 [1, 0] 또는 [0, 1]을 사용할 경우 → categorical_crossentropy.
Dense(1, sigmoid)와 0/1 타겟을 사용할 경우 → binary_crossentropy.
출력 형태·타겟 표현·손실함수는 한 세트로 맞춘다. softmax라고 타겟을 반드시 원핫 인코딩해야 하는 것은 아니다.


예측과 평가

예측 결과 → (리뷰 수, 2) 배열. 열 0은 부정 확률, 열 1은 긍정 확률.
pred.argmax(axis=-1) → 확률이 가장 큰 열의 번호를 최종 클래스 0/1로 선택.
각 확률을 따로 0.5와 비교하기보다 argmax로 하나의 클래스를 선택한다.
예제 파일의 새 리뷰 예측 부분에 남은 sigmoid용 0.5 비교는 softmax 출력에 맞게 argmax로 읽는다.
confusion_matrix()와 crosstab() → 실제·예측 비교. precision_score(), recall_score(), f1_score() → 긍정 클래스 중심 평가.
클래스가 세 개 이상으로 늘어나면 출력 수와 타겟 번호 범위를 맞추고 지표의 평균 방식도 지정한다.


학습 점검

EarlyStopping → 검증 손실 기준으로 중단하고 최적 가중치 복원. 학습·검증 그래프와 시험셋 성능을 함께 본다.
새 리뷰도 동일한 단어 사전, 번호 보정, 어휘 제한, 패딩을 적용한다.
출력 방식만 바꿨다고 새로운 감성 클래스가 추가되는 것은 아니다.


필수 함수

Dense(클래스 수, softmax) → 클래스별 확률. compile(loss='sparse_categorical_crossentropy') → 정수 타겟 학습.
predict().argmax(axis=-1) → 클래스 선택. evaluate()와 분류 지표 함수 → 최종 평가.
