3장  연관분석


핵심 이해

연관분석 → 거래나 문서에서 항목들이 함께 등장하는 규칙을 찾는다.
X → Y → X가 있는 거래에서 Y도 나타나는 경향. 인과관계나 발생 순서를 뜻하지 않는다.
분석 자료 → cf_basket.csv의 장바구니 거래와 경제뉴스 20개의 명사 목록.


전체 흐름

거래별 항목 목록 준비 → apriori로 규칙 생성 → 조건과 결과 분리 → 지지도·신뢰도·향상도 정리 → 기준에 맞는 규칙 비교.
뉴스에서는 기사 하나가 거래 하나에 해당한다. 문서 안의 단어 반복 횟수와 문서 사이의 동시 출현을 구분한다.


연관분석 지표

지지도(support) → 전체 거래 중 X와 Y가 함께 있는 비율. support(X∪Y) = 함께 있는 거래 수 / 전체 거래 수.
신뢰도(confidence) → X가 있는 거래 중 Y도 있는 비율. confidence(X→Y) = support(X∪Y) / support(X).
향상도(lift) → Y의 기본 출현 비율에 비해 X가 있을 때 Y가 얼마나 더 나타나는지 비교.
lift(X→Y) = confidence(X→Y) / support(Y) = support(X∪Y) / (support(X) × support(Y)).
lift > 1 → 함께 나타나는 경향이 높음. lift = 1 → 독립일 때와 같은 비율. lift < 1 → 함께 나타나는 경향이 낮음.
X→Y와 Y→X의 신뢰도는 달라질 수 있다. 향상도가 커도 거래 수가 적으면 지지도를 함께 확인한다.


규칙 생성과 뉴스 실습

apriori() → min_support, min_confidence, min_lift 이상인 규칙 추출. 반환 결과는 list()로 모아 확인한다.
예제 장바구니 기준 → min_support=0.15, min_confidence=0.1, min_lift=1.001.
items → 함께 나타난 항목 집합. ordered_statistics → 방향별 조건, 결과, 신뢰도, 향상도.
item_base → lhs 조건. item_add → rhs 결과. 같은 항목 집합에서도 여러 방향의 규칙이 나온다.
뉴스 전처리 → 제목과 요약 합치기 → NNG·NNP 선택 → 기사·기자 불용어 제거 → 2글자 이상 명사 선택.
규칙표 → lhs, rhs, support, confidence, lift. 향상도·신뢰도·지지도로 정렬해 확인한다.


필수 함수

csv.reader() → 거래별 항목 읽기. pos() → 뉴스 품사태깅.
apriori() → 연관규칙 생성. DataFrame() → 규칙표 작성. sort_values() → 지표 기준 정렬.
