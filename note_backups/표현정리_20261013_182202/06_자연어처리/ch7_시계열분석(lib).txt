7장  시계열 분석  Statsmodels와 Prophet


핵심 이해

시계열 → 시간 순서대로 기록된 데이터. 수업은 2022년 일별 대기오염도에서 공항대로 측정소의 미세먼지 농도를 분석한다.
Statsmodels → 시계열을 추세·계절성·잔차로 분해해 흐름을 살핀다.
Prophet → 추세와 계절성 등을 모델링하고 미래값을 예측한다. 휴일 효과는 관련 설정을 추가해 사용한다.


전체 흐름

cp949 CSV 읽기 → 결측치와 측정소 확인 → 측정일시를 날짜로 변환 → 측정소 선택 → 시간순 정렬과 간격 확인 → 분해 → Prophet 학습 → 미래 30일 예측.
측정소들이 섞인 전체 표를 하나의 시계열로 사용하지 않는다. 측정소와 예측할 농도 열을 먼저 선택한다.


시계열 분해

날짜 인덱스 → set_index('측정일시'). 분석값 → 미세먼지 농도.
seasonal_decompose(period=30, model='additive') → 30개 관측을 한 주기로 가정해 분해한다.
observed → 실제 관측값. trend → 장기적인 증가·감소 추세.
seasonal → 반복되는 패턴. resid → 추세와 계절성으로 설명되지 않는 잔차.
additive → 실제값 = 추세 + 계절성 + 잔차. period=30은 수업의 가정이며 실제 반복 주기인지 확인한다.
분해 전 결측치와 일정한 시간 간격을 확인한다.


Prophet 입력과 결과

ds → 날짜 열. y → 실제값 열. 이 이름으로 학습 데이터를 준비한다.
Prophet().fit() → 모델 학습. make_future_dataframe(periods=30) → 기본 일 단위의 미래 30일 날짜 생성.
predict() → 날짜별 예측. 결과에는 과거 날짜와 미래 날짜가 함께 포함될 수 있다.
yhat → 예측값. yhat_lower와 yhat_upper → 예측 불확실성의 하한과 상한.
plot() → 실제값과 예측 흐름. plot_components() → 추세·계절성 등 구성 요소.


평가에서 볼 것

미래 예측 성능 → 과거 기간으로 학습하고 이후 기간의 실제값과 비교한다.
전체 자료로 학습해 얻은 미래 곡선만으로 예측 정확도를 확인할 수 없다. 예측값과 불확실성 범위를 함께 읽는다.


필수 함수

pd.to_datetime() → 날짜 변환. isna() → 결측치 확인. set_index() → 날짜 인덱스 설정.
seasonal_decompose() → 분해. Prophet(), fit(), make_future_dataframe(), predict() → 미래 예측.
plot_components() → 예측 구성 요소 확인.
