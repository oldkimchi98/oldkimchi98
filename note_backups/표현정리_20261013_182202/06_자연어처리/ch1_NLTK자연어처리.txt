1장  NLTK 자연어처리


핵심 이해

자연어처리 → 사람이 사용하는 글을 분석할 수 있는 단위로 나누고, 빈도·품사·문맥 등을 살핀다.
말뭉치(Corpus) → 분석에 사용할 텍스트 모음. 수업은 Gutenberg의 austen-emma.txt를 사용한다.
토큰 → 문장이나 단어처럼 분석을 위해 나눈 단위. 단어의 출현 횟수와 단어 종류 수는 다르다.


전체 흐름

말뭉치 읽기 → 문장·단어 토큰화 → 정규표현식으로 분석 대상 선택 → 어간추출 또는 품사태깅 → 명사 추출 → 빈도와 등장 위치 시각화.
len(words) → 반복을 포함한 전체 토큰 수. len(set(words)) → 중복을 제외한 토큰 종류 수.


토큰화와 어간추출

sent_tokenize() → 문장 단위로 분리. word_tokenize() → 단어와 문장부호 등을 토큰으로 분리.
RegexpTokenizer() → 정규표현식에 맞는 토큰 추출. [a-zA-Z]{3,} → 영문자로만 이루어진 3글자 이상 토큰 추출.
\w → 영문자만 의미하지 않는다. 숫자, 밑줄과 유니코드 문자도 포함하므로 분석 목적에 맞게 패턴을 정한다.
PorterStemmer와 LancasterStemmer → 규칙으로 단어의 어간을 추출. RegexpStemmer → 지정한 패턴을 제거.
어간추출 결과가 항상 사전에 있는 단어가 되는 것은 아니다.


품사태깅과 Emma 실습

pos_tag() → (단어, 품사) 쌍을 반환한다.
NN → 일반 단수 명사. NNS → 일반 복수 명사. NNP → 단수 고유명사. NNPS → 복수 고유명사.
명사 추출 → 태그가 NN, NNS, NNP, NNPS인 단어만 선택한다.
Emma 실습 → 조건에 맞는 단어 추출 → 품사태깅 → Emma 출현 횟수와 품사 종류 확인 → 명사 종류 수 계산.
품사별 등장 횟수 → 딕셔너리 또는 Series로 누적한다. 대소문자 처리 여부에 따라 빈도가 달라진다.


필수 함수

nltk.download() → 실습에 필요한 말뭉치와 분석 자료 다운로드. corpus.gutenberg.raw() → 원문 읽기.
Text() → 토큰 목록을 빈도 분석 대상으로 구성. vocab()과 FreqDist() → 단어 빈도 확인.
most_common(n) → 빈도 상위 n개. count() → 특정 단어의 출현 횟수.
plot(n) → 상위 단어 빈도 시각화. dispersion_plot() → 단어가 텍스트의 어느 위치에 등장하는지 확인.
